## Status discipline

`ESTABLISHED` = directly chosen by Ink in the current workshop. `INHERITED/VERIFIED` = present in a named source at a specified scope. `PROPOSED` = offered for consideration; not canon. `OPEN` = deliberately unresolved. `SUPERSEDED` = historical decision explicitly replaced. `VISUAL REFERENCE` = artwork without automatic lore authority. Details retain their status across chats.

## Authority boundaries

1. **Ink's newest explicit MK231-series decision** controls MK231. Correct only the explicitly named dimension; never silently change unrelated details.
2. **MK Ultra / `_bricked`** own mathematical terminology and source-status limits (L0). Mathematical conjectures are not newly proven by an attractive fantasy analogy.
3. **MK147** supplies compatible fantasy, `vaen`, `ru’ne`/sigil arrays, Binding Circles, world and cultural foundations (L1/L2). MK147’s legacy *story* is not the MK231 story.
4. **MK157** is *selective reference*: Afflicted/Kira biology, certain transduction definitions and useful cultural examples. Its Valnak/Elara/Armor arc and original Kira age are **not** imported as MK231 narrative events.
5. **`_raeon`** governs original raeon game mechanics where imported as cultural inheritance.
6. Old checkpoints remain inspectable in `history/`, but are subordinate to later explicit corrections; illustrations do not supersede prose decisions.
