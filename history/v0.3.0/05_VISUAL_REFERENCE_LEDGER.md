# VISUAL REFERENCE LEDGER — SELECTIONS, REJECTIONS AND CANON STATUS

Visual references are **descriptive aids**, not definitions of underlying biological mechanisms, character profession, symbolic identity or anatomy. Decorative AI-generated text in image margins does **not** independently create canon. This is essential: some images contain labels like *spirit* or *purity* that the author never adopted and that can contradict the explicit 'no spirits' rule.

All images listed here are included under `visuals/` in this ZIP when available. Filenames are exact copied source files in this archive.
